New update released, covers any reported issues, some other bugs found and added all requested features.

Version 2.2.0:  
- New: support for party size mods, additional pawns show in the menu automatically.  
- New: "Allow hired pawns to level from EXP" (Options + Debug), hired pawns level up from the EXP they earn and the status screen shows their EXP  
- New: DLC appraisal roll editor, set physical, magick, knockdown, weight and the bonus on appraised gear, kept inside the game's own roll limits for that item (pawns and Arisen gear), with Best roll and Original roll  
- New: "No skill (empty slot)" option to clear a skill slot  
- New: "Also use this name as the moniker", the name some menus and the party list show  
- New: Reset and Restore core skills buttons  
- New: Validate Pawn flags appraisal stats and bonuses a real drop can't roll  
- Fixed: Silent, Less and Rare chatter didn't stop pawns talking  
- Fixed: hired pawns that drowned, died or were dismissed lost their settings, they now come back when the same pawn is hired again  
- Fixed: restoring gear now also puts back the original appraisal roll  
- Fixed: a rare error when a pawn appeared a frame before its character finished loading

Version 2.1.1:  
- Fixed: pawns turning invisible (respawn option, loading race, and changes now run on the game thread)  
- Fixed: gear changes now show immediately, no pause or reload needed (weapons, shields and armour)  
- Fixed: "Show items for all vocations" filter, unticked now really filters by vocation  
- Fixed: specialization not applying, instant revive not reviving  
- Fixed: respawn option now revives the pawn when their death timer ends instead of losing them  
- Fixed: infinite carry weight now also shows Light in the menu  
- Fixed: removing skill or augment overrides puts the pawn's original skills back exactly, even after several changes, and picking one that's already in another slot never leaves duplicates  
- Fixed: restoring original skills and augments now also clears slots that were empty to begin with  
- Fixed: older saved originals now fill in the newer skill and augment slots  
- New: all 6 weapon skill slots and the 7th augment slot, with an extra augment slot unlock  
- New: core skills (vocation skills like Kite Shot), carried by presets  
- New: "Apply skills as the upgraded variant"  
- New: vocation rank filter for skills, with Master and DLC skills labelled  
- New: "Keep augments when changing vocation"  
- New: hired pawns can be set to any level, up or down  
- New: "Remove all dropped items" (Misc > Arisen QoL + Testing)  
- New: Validate Pawn also flags skills above the pawn's rank and special skills on mantles  
- New: first start guide and a "How to use" section  
- New: yellow highlight on anything changed from its default, and the original value next to every option  
- Changed: presets now save only the options you set in the mod, Copy from does the same, Import/Export copies a whole pawn  
- Changed: "Enable Control" renamed to "Edit this pawn"  
- Changed: special skills can no longer be set on mantles (the game ignores them)
