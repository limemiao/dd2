# More Pawns V3 — Fluffy Mod Manager package

1. Install REFramework for Dragon's Dogma 2.
2. Import this archive into Fluffy Mod Manager for Dragon's Dogma 2.
3. Enable **More Pawns V4**.
4. Do not enable another More Pawns autorun script at the same time.

V4 retains V3's party, pawn-name, and vocation-crest features and gives the two extra hires their own formation slots.

4.0.4-test1 reserves a slot for the Arisen in the game's four-slot portrait cache. It removes the 4.0.2/4.0.3 shared-model-pool reset, which could invalidate preview models still referenced by menus. The menu layout and portrait cache retain their stock capacity; this does not add six simultaneous portraits.

This is a test build. A targeted live repair produced a valid, built, capture-ready Arisen portrait; fresh-session validation of Pause, Items, and Equipment is still required. Restart the game after replacing the autorun script. Enable only one More Pawns script.

REFramework runs this Lua-only mod. DD2 loose native-asset mods additionally require REFramework's Loose file loader; this archive contains no native assets or PAK.
