# 龙之信条 2 综合资料库

这个目录把装备图鉴和职业技能图鉴整合在同一个页面中。

## 文件

- `index.html`：综合资料库，可切换“装备图鉴”和“职业技能”，共用搜索；
  装备页可按职业、武器／防具和装备部位组合筛选。
- `bundle.json`：装备、职业、技能和追随者特技的合并数据。
- `preview.png`：首页预览。

## 收录统计

- 装备：1091 件，其中 1091 件有游戏原图标。
- 职业技能：243 个分组，共 408 个等级或版本记录。
- 职业：10 个。
- 追随者特技：6 个。

装备图标、名称、数值和职业限制来自装备资料；技能名称、说明、操作方式、职业等级
和技能点消耗来自职业技能资料。两个原始目录和其中的 CSV 文件仍然保留。
