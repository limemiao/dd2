# 龙之信条 2 职业技能图鉴

本目录直接从游戏 PAK 中的技能资料和简体中文消息表生成。

## 文件

- `index.html`：按职业浏览、搜索和按技能类型筛选的离线图鉴。
- `skills.csv`：逐等级、逐版本的技能表格，可用 Excel 打开。
- `skills.json`：按职业归档的完整结构化数据。
- `summary.json`：条目数量和分类统计。
- `preview.png`：图鉴首页预览。

## 收录范围

- 基础动作：普通攻击、瞄准、防御等基础战斗动作。
- 核心技能：职业核心技能及其扩展版本。
- 武器技能：主动技能、等级 1/2、EX 强化和扩展技能。
- 强化能力：各职业的被动强化能力。
- 追随者特技：不限定职业的六项追随者特技。

每条记录保留游戏内的操作提示、职业等级要求、技能点消耗和完整技能说明。
技能资料中的显示标签、颜色标签和文字引用已经转换为可读文本。

当前统计为 10 个职业、243 个技能分组、408 个等级或版本记录，以及 6 个
追随者特技。
